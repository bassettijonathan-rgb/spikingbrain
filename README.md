# spikingbrain

Soft-bodied creatures controlled by spiking neural networks (Izhikevich neurons, reward-modulated
STDP) that learn during their lifetime and evolve across generations, built to watch the Baldwin
effect and genetic assimilation emerge.

- Design: [DESIGN.md](DESIGN.md)
- Live page: https://bassettijonathan-rgb.github.io/spikingbrain/

```
npm install
npm run dev                  # browser
npm test                     # tests
npm run sim -- --seed 42     # headless runner
```
